# Breathlessness Guide

A clinical reference application built to assist medical professionals and students with key assessment questions for a patient presenting with breathlessness. The app offers a clean, responsive interface to quickly pull up relevant questions grouped by clinical history categories.

## Features
- **Categorized Assessment**: Quick access to essential questions including Onset, Provocation, Severity, and Associated Symptoms.
- **Responsive Layout**: Designed to look great on mobile phones, tablets, desktop, and web.
- **Clean UI**: Easy to read typography, soft cards, and distraction-free design to support quick reference during clinical encounters.

## Tech Stack
- Flutter
- Material 3 Design
- Cross-platform support (iOS, Android, Web, Desktop)

## Running the App

```bash
flutter pub get
flutter run
```
